# 什么是五段模型

## 一句话

把「一件衣服值多少钱」这个模糊问题，拆成五段加法，每一段都能查到出处，或者明确标为估算。

```
真实价值 = 材料成本 + 加工成本 + 设计成本 + 品牌溢价 + 允许溢出价值
```

## 五段分别是什么

| 段 | 是什么 | 数据来源 | 性质 |
|---|---|---|---|
| 材料成本 | 面料 / 里料 / 填充 / 辅料 / 五金，支持混纺 | 水洗标（成分）× 官方指数（单价） | 出厂成本 |
| 加工成本 | 裁剪、缝制等工序 | 按品类「元 / 件」 | 出厂成本 |
| 设计成本 | 打版、样衣、设计投入 | (材料 + 加工) × 设计费率 | 出厂成本 |
| 品牌溢价 | 品牌带来的附加价值 | 上市公司毛利率派生 | 定价结果 |
| 允许溢出 | 运费、人工、佣金等流通成本 | 用户自定比例 | 流通成本 |

## 关键：三类东西不能糊在一根加法线上

这是整个模型最容易算歪的地方：

1. **材料 + 加工 + 设计 = 出厂成本**（商家真正花掉的钱）
2. **允许溢出 = 流通成本**（从出厂到消费者手里花的钱）
3. **品牌溢价 = 定价结果**（消费者愿意多付的钱，不是商家花掉的钱）

把这三类直接相加，再拿去和售价比，会出三个问题：

- **口径不清**：结果到底是「出厂价」还是「到手价」，基准没说清
- **品牌溢价自我实现**：把品牌溢价并进「真实价值」再和售价比，等于「售价 = 价值」恒成立，奢侈品牌永远不算贵
- **溢出自证**：允许溢出让用户拖滑块，能拖出任意结论

> 正确姿势：默认给「出厂成本口径」当主结论，流通项单列，品牌溢价单独展示、**不算进成本底线**。

## 为什么必须下钻到子项

只给五个总数，等于没做。用户要的是「看得明白钱花在哪」：

```
材料成本 → 主料 + 里料/填充 + 辅料 + 五金 + 吊牌包装
加工成本 → 裁剪 + 缝制 + 后处理 + 整烫 + 质检包装
设计成本 → 打版 + 样衣 + 设计稿/买版
```

规则：

- **成本类**（材料 / 加工 / 设计）：子项求和 = 那一级；缺数据的子项**留空显示「未计入」**，不许填 0 假装算过
- **加成类**（品牌溢价 / 允许溢出）：保持「前序项 × 费率」，不拆子项求和——它们本质是加价，不是成本项，拆成子项会假装精确

## 用户只该答一个问题

这是做界面时反复推翻后得到的结论，值得记下来：

**用户的信息源只有水洗标，而他只认得出「面料」那一行。** 里料是什么纤维、充绒多少克，标签上要么没写、要么没人注意。把这些做成输入项，结果不是「填得更全」，而是**用户随手挑一个凑数**，把估价建在假成分上。

所以：**界面只让用户答「面料成分」一个问题**，其余部位（里料 / 填充 / 辅料）由系统按品类自动补，并**逐条汇报**补了什么、依据是什么、算了多少钱。「钱从哪来」不能说成「你不需要知道」。

## 已知缺口（诚实列出来）

当前模型还没计入这些真实成本项，后来者若要复用，务必先补：

- **面辅料损耗率**：用户填的是净用量，实际要按排料损耗加放（针织 8~12%、梭织 5~8%、羽绒 10~15%），不补会系统性低估材料
- **次品 / 报废率、质检合规检测费**（GB 18401 / GB 31701 按款送检）
- **打版费 / 样衣费摊薄**（现在用固定比例代替，批量小就低估）
- **吊牌 / 洗标 / 包装**（单件几毛到几块，占比 3~8%）
- **增值税**（13%）、**平台佣金**、**退换货损耗**（服装电商退货率可达 30~50%）、**库存季末打折**（售罄率通常仅 60~70%）、**资金占用**
