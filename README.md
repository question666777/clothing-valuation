# 给衣服估真实价值：一套可借鉴的拆解方法论

> 这不是一个上线的产品，而是一份「指路牌」—— 把「一件衣服到底值多少钱」这件事，
> 从模糊的直觉，拆成一笔能算、能查、能对质的账。留在这里，给以后有同样想法的人借鉴。

## 它回答什么问题

你看到一件标价 899 的衣服，想知道它的「真实价值」大概多少、溢价有多狠。
这个项目给出一条拆解路径：把真实价值分成五段，每一段都能查到出处，或者明确标为估算。

```
真实价值 = 材料成本 + 加工成本 + 设计成本 + 品牌溢价 + 允许溢出价值
```

## 核心不是代码，是「口径」

代码（`core/` + `config/`）只是一个参考实现。真正值钱的是这套口径：

- **材料价只认官方源**，不凭常识填（见 `docs/02`）
- **官方只按「纤维 × 规格档」报价，没有「面料名」档** —— 识别只能给纤维线索，不能编价
- **缺数据就降级留空**，不许拿 0 冒充有效价
- **每笔钱都能下钻到子项**，看得明白钱花在哪

## 边界与取舍

这套模型把话说清楚：它算的是「出厂成本」口径的真实价值底线，不是全生命周期总成本。几个刻意取舍：

- **材料 / 加工 / 设计三段 = 出厂成本底线**；品牌溢价是「定价结果」、允许溢出是「流通成本」，两者都不混进成本底线（口径见 `docs/01`）
- **损耗、退换货、季末打折、增值税、平台佣金、资金占用**属于流通与经营成本，本模型明确不纳入「出厂成本」；要算全成本就并入「允许溢出」段或单列，别和材料 / 加工 / 设计混加（补法和参数区间见 `docs/01`）
- **价格取发版快照**：实时价不是本方法论的必要条件；参考实现给了抓取入口，若要实时可选微信云开发（免备案）或自建后端（需备案）
- **加工费、典型克重、辅料单价是行业估算**，已标 `estimate`；接入自己核实的官方源即可替换

一句话：**没有「没做完」，只有「有意不纳入 + 说清怎么补」。**
