# 一件衣服的成本到底是多少？—— 一套能算、能查、能对质的拆解方法

> 给所有想「看穿一件东西真实价值」的人。这里不直接给你答案，而是给你一套**自己能把账算清楚**的方法。

## 这是什么（30 秒看懂）

看到一件标价 899 的衣服，想知道它的真实价值、溢价有多狠？这个仓库把「值多少钱」从模糊的直觉，拆成一条**能算、能查、能对质**的路径：

```
真实价值 = 材料成本 + 加工成本 + 设计成本 + 品牌溢价 + 允许溢出价值
```

核心不是代码，是**口径**：材料价从哪来、怎么不编数字、缺数据怎么办。代码（`core/` + `config/`）只是一个参考实现。

## 你能从这里带走什么

- ✅ **五段拆解模型**：材料 / 加工 / 设计 / 品牌溢价 / 溢出，每一段怎么算、数据从哪来
- ✅ **官方数据源清单**：棉花 / 羽绒 / 生丝 / 羊绒… 去哪查、怎么核验（`docs/02`，已实测可访问）
- ✅ **17 条踩坑记录**：识别 / 数据 / 界面三类真实坑，每条都是「不报错、但结果错」（`docs/03`）
- ✅ **2500 行零依赖代码**：`core/` 纯计算 + `config/` 数据口径，可直接复用
- ✅ **迁移路径**：怎么把这套思路套到你自己的领域（`docs/04`）

## 谁适合看

- 想搞懂「一件衣服的成本结构、钱花在哪」的买手 / 电商从业者 / 消费者

## 一句话说清口径红线

- **材料价只认官方源**，不凭常识填；查不到就标「估算」，绝不拿 0 冒充有效价
- **官方只按「纤维 × 规格档」报价**，没有「面料名」档 —— 识别只能给纤维线索，不能编价
- **每笔钱都能下钻到子项**，缺数据的子项留空显示「未计入」，不假装算过

## 边界（诚实）

本模型算的是「出厂成本」口径的真实价值底线，不是全生命周期总成本。损耗、退换货、税、佣金等流通与经营成本**有意不纳入**（怎么补见 `docs/01`）。价格取发版快照，实时化是可选扩展。

没有「没做完」，只有「有意不纳入 + 说清怎么补」。
