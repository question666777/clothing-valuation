# 看光光

**买东西前拍一下，看看它到底值多少钱。**

看光光是一款「看穿价格」的工具：拍照识别衣物，按五段模型估算它的真实价值区间，再和你看到的售价对比，帮你判断这笔钱花得值不值。

## 它怎么算的（五段模型）

```
真实价值区间 = 材料成本 + 加工成本 + 设计成本 + 品牌溢价 + 允许溢出价值
```

| 段 | 说明 | 数据来源 |
|---|---|---|
| 材料成本 | 面料 / 里料 / 填充 / 辅料 / 五金，支持混纺 | 水洗标（成分）+ 政府价格监测 / 纺织指数（单价） |
| 加工成本 | 裁剪、缝制等工序 | 按品类「元 / 件」 |
| 设计成本 | 打版、样衣、设计投入 | (材料 + 加工) × 设计费率，按「品牌 × 系列」取 |
| 品牌溢价 | 品牌带来的附加价值 | 由上市公司定期报告毛利率派生，不手填 |
| 允许溢出 | 运费、人工、佣金等流通成本 | 用户自定比例，系统给品类推荐初值 |

核心卖点：**每个数都能下钻到子项，让你看得明白钱花在哪**，而不是只给一个总数。

## 当前状态

- **载体**：微信小程序（先行），手机 App（React Native + Expo）为最终目标，两端共享同一份 `config/` + `core/` 代码
- **范围**：只做衣物（鞋、包已移出，配饰保留）
- **运行时零联网**：数据在包里、计算在端上、OCR 走微信 VisionKit —— 不需要服务器 / 域名 / 备案，上线只要注册 + 审核
- **版本**：v0.20（草案，早期设想阶段）

## 技术栈

- 小程序：原生 WXML / WXSS / JS
- 共享逻辑层：`config/`（数据与系数）+ `core/valuation/`（纯计算，不读配置、不碰网络）
- 识别：水洗标文字 OCR 走 VisionKit（端上）；多模态大模型识别已规划（需服务端中转）
- 校验：多道脚本，当前全绿

## 目录结构

```
config/        配置与系数（纤维价 / 面料 / 品牌 / 系数）—— 真源
core/          五段估值纯计算 —— 真源
services/      识别 + 登录服务 —— 真源
src/           RN / Expo 界面层（原地保留、暂不维护）
miniprogram/   微信小程序工程（开发者工具导入此目录，不是仓库根）
  pages/       手写页面
  config/ core/ services/ styles/   ← 由根目录同步生成的产物，禁止手改
scripts/       同步 + 校验脚本
server/        价格抓取（永不进小程序包）
preview/       实算生成的 HTML 预览
```

## 快速开始

小程序：用微信开发者工具导入 `miniprogram/` 目录。

```bash
npm run sync:mp       # 根目录真源 → 同步进 miniprogram/
npm run verify:all    # 核心 + 小程序双向校验
npm run smoke:page    # 页面事件处理函数真跑
npm run smoke:auth    # 登录态真跑
npm run preview       # 生成 HTML 预览（数字全部实算）
npm run prices        # 抓取官方价格并与现值对拍（只报告、不改配置）
```

## 设计红线（节选）

完整规范见 `AGENTS.md`（开发指令）与 `PRD.md`（产品需求）。

- **不许编数字**：任何进计算的价格 / 费率必须有出处，否则标 `estimate`；取不到价就 `null` + 降级，不许拿 0 冒充
- **材料价只认中国官方源**（机构 + URL + 数据期 + 抓取日）
- **识别结果必须经用户确认 / 修正**才进估价；结果页永远有「估值仅供参考」
- 官方只按「纤维 × 规格档」报价，没有「面料名」档；识别只给纤维线索，推不出就不猜
- 成分占比必须凑齐 100%（±1%），否则该条降级、不给单价

## 已知缺口

加工费、典型克重、辅料单价 / 单耗仍是行业估算；损耗 / 退换货 / 售罄率、后端方案（微信云开发 vs 自建）、价格定时更新等标记为【待定】。
